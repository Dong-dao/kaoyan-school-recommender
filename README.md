# 考研院校推荐系统

## 项目概述

这是一个基于 React + TypeScript + Vite + Tailwind CSS 开发的智能考研院校推荐系统，参考高考志愿填报系统的设计理念，为考研学生提供"冲、稳、保"三段位院校推荐服务。

## 核心功能

### 1. 智能信息采集
- **本科院校输入**：支持手动输入本科学校名称
- **目标专业选择**：提供热门专业快速选择（计算机、软件工程、人工智能等）
- **模拟分数录入**：
  - 总分（必填）
  - 英语分数（必填）
  - 数学分数（选填）
  - CET-4/CET-6 成绩（选填）

### 2. 冲稳保三段位推荐
基于用户模拟分数，智能推荐三个档位的院校：

| 档位 | 说明 | 特点 |
|------|------|------|
| 🚀 冲一冲 | 录取分数高于用户分数 20-40 分 | 顶尖名校，需要努力冲刺 |
| ⭐ 稳一稳 | 录取分数与用户分数相当 (±10) | 匹配度最高，重点考虑 |
| 🛡️ 保一保 | 录取分数低于用户分数 15-30 分 | 录取概率高，作为保底 |

### 3. 院校详情展示
每个推荐院校卡片包含：
- **院校名称**和**层次标签**（985/211/双一流）
- **学位类型**：学硕 / 专硕 / 专业组
- **录取分数线**：
  - 最低录取分
  - 平均录取分
  - 最高录取分
  - 分数匹配度可视化进度条
- **预计录取率**：颜色编码显示风险等级
- **地理位置**：城市信息
- **官网链接**：直达高校研究生招生网
- **可展开详情**：包含院校简介、复录比等详细信息

### 4. 数据可视化
- 分数范围条形图，直观显示用户分数在录取区间中的位置
- 录取率颜色编码（绿色>30%，黄色15-30%，红色<15%）
- 冲稳保三档位色彩区分（红/黄/绿）

## 技术栈

### 前端技术
- **框架**: React 18 + TypeScript
- **构建工具**: Vite 5
- **样式方案**: Tailwind CSS 3
- **图标库**: Lucide Icons
- **设计风格**: Data-Dense Dashboard 风格

### 设计系统
- **主色调**: 蓝色系 (#1E40AF, #3B82F6)
- **辅助色**: 绿色(CTA)、黄色(警告)、红色(危险)
- **字体**: Fira Sans / Fira Code
- **背景**: 渐变蓝白 (#EFF6FF)

## 使用方法

### 开发环境运行
```bash
cd app
npm install
npm run dev
```

访问 http://localhost:5173/ 查看效果

### 生产环境构建
```bash
npm run build
```

构建产物输出到 `dist/` 目录

## 功能演示流程

1. **访问首页** → 看到系统介绍和统计数据
2. **填写表单** → 输入本科院校、目标专业、模拟分数等
3. **提交查询** → 系统生成冲稳保三段位推荐结果
4. **查看结果** → 浏览各档次推荐的院校列表
5. **查看详情** → 点击"详情"按钮查看院校完整信息
6. **访问官网** → 点击"官网"按钮跳转到高校招生网
7. **重新填写** → 点击"重新填写"返回首页修改条件
